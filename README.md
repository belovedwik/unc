# Благодійний фонд У.Н.С.

Перша оновлена версія сайту [unc.org.ua](https://unc.org.ua/): сучасний односторінковий макет, українська / англійська, готовність до GitHub Pages.

## Локальний перегляд

Відкрийте `index.html` у браузері або запустіть локальний сервер з кореня репозиторію.

## GitHub Pages

1. Завантажте репозиторій на GitHub.
2. Settings → Pages → Source: **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`.
4. Сайт з’явиться за адресою `https://<username>.github.io/<repo>/`.

Відносні шляхи вже налаштовані під project pages, не лише під домен у корені.
